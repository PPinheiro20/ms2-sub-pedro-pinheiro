# Sabor & Saber — Cardápio

## 1. Nome do projeto e tema

**Nome do projeto:** Sabor & Saber

**Tema:** Site de cardápio de restaurante.

---

## 2. Descrição do que o site faz

O Sabor & Saber é um site desenvolvido para apresentar o cardápio de um restaurante de forma organizada e responsiva.

O site apresenta diferentes categorias de pratos, como entradas, pratos principais e sobremesas.

Cada prato é apresentado em cards contendo seu nome e descrição.

Também possui uma área de contato com informações do restaurante e uma barra de navegação para facilitar o acesso às seções.

---

## 3. Framework utilizado e versão

O projeto utiliza o framework:

* **Bootstrap 5.3.8**

O Bootstrap foi instalado utilizando o npm:

```bash
npm install bootstrap
```

---

## 4. Como instalar e rodar

### Instalar as dependências

No terminal, dentro da pasta do projeto, execute:

```bash
npm install
```

Esse comando instala o Bootstrap e as demais dependências presentes no `package.json`.

### Executar o projeto

Após a instalação, abra o arquivo:

```text
index.html
```

diretamente no navegador.

O Bootstrap é utilizado a partir da instalação presente na pasta `node_modules`.

---

## 5. Seções implementadas

O site possui as seguintes seções:

* **Início** — apresentação do restaurante.
* **Entradas** — pratos de entrada disponíveis no cardápio.
* **Pratos Principais** — principais opções de pratos.
* **Sobremesas** — opções de sobremesas.
* **Contato** — informações de contato e endereço do restaurante.
* **Rodapé** — informações finais do site.
